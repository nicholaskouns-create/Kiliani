# FamilySearch identifiers

Every person in the direct line, with the FamilySearch Family Tree identifier that
locates them. Captured November 2026 from the tree as displayed.

**What these are worth.** An identifier is a locator, not a verdict. FamilySearch
Family Tree profiles are user-edited and, for the generations before about 1800,
derivative in exactly the sense this archive already grades them. What changes with
an ID is that a claim becomes *checkable by anyone* instead of asserted: the profile
can be opened, its attached sources inspected, and its edit history read. Nothing in
this table upgrades a confidence label on its own.

Open a profile at `https://ancestors.familysearch.org/en/<ID>` (sign-in required).
